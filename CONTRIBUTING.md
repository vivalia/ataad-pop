# Contributing

Contributions that improve reproducibility, validation, documentation, or safety are welcome.

1. Open an issue describing the proposed change.
2. Create a focused branch and add tests for behavioral changes.
3. Run `ruff check .` and `pytest` before opening a pull request.
4. Do not commit clinical data, patient-level predictions, credentials, or institutionally restricted artifacts.
5. Clearly distinguish confirmatory analyses from post-freeze or exploratory analyses.

Clinical definitions, endpoint changes, feature-channel assignments, and deployment claims require investigator review and must not be altered as purely technical refactors.
