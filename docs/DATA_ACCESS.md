# Data availability and access boundary

Patient-level data are not publicly released because they contain sensitive clinical information. Data supporting the associated findings may be requested from the corresponding authors and can be shared only when institutional, ethics, legal, and data-security requirements are satisfied.

A request should describe the research question, requested variables, analysis plan, data-protection controls, intended retention period, and responsible institution. Approval may require a data-use agreement and analysis within an approved secure environment.

The public repository provides code, non-patient feature metadata, aggregate results, and a synthetic schema-compatible example. Synthetic data are generated independently and must not be interpreted as anonymized real records.
