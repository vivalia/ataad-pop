# Security and Privacy Policy

## Supported version

Security and privacy fixes are applied to the latest release and the default branch.

## Reporting

Do not open a public issue for a suspected patient-data disclosure, credential leak, or exploitable vulnerability. Contact the maintainers privately through the repository owner's GitHub profile.

## Prohibited content

Raw clinical workbooks, patient-level predictions, direct or quasi-identifiers, access tokens, private keys, and institutional credentials must never be committed. If restricted data are accidentally committed, stop distribution, revoke exposed credentials, notify the data custodian, and rewrite repository history before any further release.
