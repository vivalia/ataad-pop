# Public aggregate results

This directory contains disclosure-reviewed summary tables and publication SVG figures. It does not contain row identifiers, per-patient predictions, imputation-specific predictions, clinical dates, or free text.

The tables reproduce reported aggregate performance, calibration, selective-prediction, missingness-stress, subgroup, domain-ablation, and algorithm-benchmark results. Exact regeneration requires authorized access to the controlled clinical dataset described in [`docs/DATA_ACCESS.md`](../docs/DATA_ACCESS.md).

These results estimate concordance with recorded historical operative decisions and must not be interpreted as causal treatment-effect evidence.
